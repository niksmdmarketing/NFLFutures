How to read this

The example line is the model average rounded to a half point, not a bookmaker price. The over chance is the model's probability that the player beats that line if he plays. These are experimental, independent model probabilities, not betting advice; no betting edge has been established.

Built from nflverse public data (play-by-play, schedules, player stats, rosters, injury reports, FTN and Pro Football Reference charting). An independent model. Probabilities only, not betting advice.
