# Conditional projections first — 24 October 2026 Sydney

User direction: build projections under explicit lineup/role assumptions; defer automatic in/out selection. Local experimental tool only. No site, live model, schedules or publication changes.

Scope: team passing-attempt environment, assumed starting-QB attempts, and receiver receptions conditional on participation and specified target roles. No new passing yards, touchdowns, rushing props, game spreads or totals. No market inputs, DNP-zero mixture, automatic injury filtering or rejected teammate-redistribution effect.

Use existing frozen 2026 team volume, receiving priors and count dispersion. Receiver target share is workload and catch probability is production. Repair default target shares proportionally only if their sum exceeds one; preserve an unallocated bucket. Explicit user shares that sum above one must fail rather than be silently changed. Every output discloses both parts.

QB assumed starting role must not mean guaranteed most attempts: early exits and relief can still occur. Fit one pooled beta-binomial attempt-share distribution from 2020–2025 first identifiable QB dropbacks and those QBs' eventual full-game attempts. This is an outcome proxy for starting role, not an announced-starter archive. Training labels only: actual future starters are never inferred automatically. Fixed 100 team-attempt shrinkage towards share 0.95, one fitted concentration. Using starters rather than only eventual most-attempts passers retains early-exit outcomes. Learn counts on existing public stats; preserve input hashes and coverage.

Default QB is the first-ranked dated depth-chart QB as a convenience ASSUMPTION, without reading injury statuses or eliminating anyone. Included receivers are assumed participating. The user can select any depth-listed QB, disable receivers or specify target-share assumptions. Disabling does not automatically redistribute their targets: the rejected redistribution test stays off. New receivers without sufficient history remain visible with an explicit position-prior fallback warning, never zero ability or invented workload certainty; they require the user to enable their projection/role before joining the default target budget. Exclusion is missing-role coverage, not a medical Out designation. Switching QB leaves team volume unchanged until a separate QB-style volume test exists.

Build a reusable command-line projector, editable JSON assumption file, complete count PMFs, means/medians/80% intervals, and arbitrary-line over/under/push calculations. Half-point examples are illustrative formula lines, not bookmaker quotes. Save input/model/assumption hashes, exact UTC generation time and source game freshness. Output create-only. Do not label this independently forward-archived or market-validated.

Validation: test normalisation, count bounds, target budget, primary-role replacement independent of tiny backup history, disabled-player behaviour, line settlement probabilities including integer pushes, no appearance/news features, and immutable prior artifacts. No promised accuracy gain or automatic adoption. Current snapshots are experimental projections, not a claim the default lineup is correct or fully healthy.
